CẬP NHẬT LOGO GÓC TRÁI + FAVICON + KHUNG SIEMENS

1. Giải nén ZIP này. Có 18 file, tất cả nằm ngoài cùng.
2. Mở repository GitHub → Add file → Upload files.
3. Chọn toàn bộ 18 file đã giải nén, upload vào thư mục gốc rồi Commit changes. Không upload chính file ZIP.
4. Chờ GitHub Pages triển khai xong rồi mở lại trang.

Logo góc trái dùng CHÍNH XÁC ảnh brand.png bạn gửi, giữ nguyên toàn bộ dữ liệu ảnh. Ảnh này được chép thêm thành brand-mark.png để tạo đường dẫn mới, tránh ảnh cũ lưu trong trình duyệt. Phải upload cả brand-mark.png, app.js, style.css và các trang HTML.

Gói này giữ các bản sửa favicon, khung Siemens và sidebar trước đó. Kích thước hiển thị logo góc trái vẫn 43×43 px; ảnh được hiển thị đầy đủ theo góc trong suốt vốn có.

Các thư mục cũ personal/, blog/, contact/, background/ vẫn chứa website cũ. Hãy dùng menu trên Dashboard và các trang personal.html, blog.html, contact.html.
