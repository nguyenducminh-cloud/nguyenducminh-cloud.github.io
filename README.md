# Minh Nguyen · Portfolio (flat upload · v2)

Tất cả file nằm ngoài cùng; không có thư mục con. Giải nén ZIP, chọn toàn bộ file rồi upload một lần vào thư mục gốc repository GitHub. File trùng tên sẽ được cập nhật khi commit; không bắt buộc xóa những thư mục website cũ.

Đọc **HUONG_DAN_UPLOAD.txt** để biết cách bật GitHub Pages, viết blog và cập nhật hồ sơ.

| File | Trang trong menu |
| --- | --- |
| `index.html` | Dashboard |
| `personal.html` | Personal · thông tin cá nhân và kỹ năng |
| `experience.html` | Work Experience · Siemens và OCB |
| `education.html` | Education · toàn bộ quá trình học tập |
| `volunteering.html` | Volunteering · Royal Melbourne Hospital và Đội Công tác Xã hội THPT chuyên Lê Hồng Phong (CTXH) |
| `blog.html` | Blog · danh sách và trang đọc bài |
| `contact.html` | Contact · liên hệ |
| `studio.html` | Writing Studio · soạn, lưu nháp và xuất bài |

Bản v2 tách công việc, học tập và tình nguyện thành ba trang riêng trong menu. Nội dung hồ sơ, kỹ năng và các mốc thời gian được giữ nguyên; nhận diện CTXH được cập nhật theo tài liệu đã cung cấp. Các logo mới là `siemens.png`, `rmh.png` và `ctxh.png`, đều nằm ngoài cùng như những file khác.

Sửa `profile.js` để cập nhật thông tin. Nháp blog lưu trong trình duyệt; xuất `posts.js` rồi upload vào thư mục gốc để đăng. File xuất gồm bài hiện có, **tất cả nháp đã lưu** và form đang mở, nên chỉ upload khi toàn bộ nội dung đã sẵn sàng công khai.

Cách xuất bản: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Không cần build hoặc cài thêm phần mềm.
