# Minh Nguyen · Portfolio (flat upload)

Tất cả file nằm ngoài cùng; không có thư mục con. Giải nén ZIP, chọn toàn bộ file rồi upload một lần vào thư mục gốc repository.

Đọc **HUONG_DAN_UPLOAD.txt** để biết cách bật GitHub Pages, viết blog và cập nhật hồ sơ.

Các trang: `index.html`, `personal.html`, `experience.html`, `blog.html`, `contact.html`, `studio.html`.

Nháp blog lưu cục bộ. Xuất `posts.js` rồi upload vào thư mục gốc để đăng.
